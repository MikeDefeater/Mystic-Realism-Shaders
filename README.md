# Mystic Realism Shaders (Minecraft 1.21.1)

Shaderpack für **Minecraft Java 1.21.1** mit **Iris** (z. B. das Modpack *Aero Wizardry* in Prism Launcher). Mystische, epische Fantasy-Stimmung: Talnebel, Lichtstrahlen durchs Laub, Nordlicht, Milchstraße und ein erdiger Kino-Look.

## Was der Shader kann

- 🌫️ **Nebel:** Dunst in der Ferne, Talnebel und wabernder **Waldnebel** nur in Wald-, Taiga-, Dschungel-, Sumpf- und Kirschhain-Biomen
- ☀️ **Lichtstrahlen** (Godrays), die durch Blätter, Wolken und Berge fallen
- 🌌 **Nachthimmel** mit Milchstraße, funkelnden Sternen und grün-violettem **Nordlicht**
- ☁️ **Realistische Wolken**, die sich ständig verformen und ziehen
- 🌳 **Realistisches Laub**: unterschiedlich gefärbte Blätter, Sonnenlicht scheint durch, wehende Pflanzen
- 💧 **Wasser** mit Wellen, Spiegelungen von Bäumen und Bergen und Trübung in der Tiefe
- 🎬 **Kino-Look**: Epic-Fantasy-Farben, Bloom, Schärfe, Klarheit, Vignette, Bewegungsunschärfe
- 📊 **5 Profile** von *Very Low* bis *Ultra*, damit es auch auf schwächeren PCs läuft
- 🔭 Unterstützt **Distant Horizons**
- 🇩🇪 Alle Einstellungen mit **deutschen Erklärungen** im Spiel (Englisch gibt es auch)

## Installation

1. **Iris** muss in der Instanz installiert sein (bei NeoForge: *Iris* für NeoForge, bei Forge: *Oculus*). Im Modpack *Aero Wizardry* ist Iris schon dabei.
2. Oben auf den Download-Link klicken. Die ZIP-Datei landet in deinem **Downloads**-Ordner. **Nicht entpacken!**
3. Minecraft starten → **Optionen** → **Videoeinstellungen** → **Shaderpakete** → **Shaderpaket-Ordner öffnen**.
   (Der Ordner ist normalerweise `%appdata%\.minecraft\shaderpacks`. Bei Prism Launcher: Rechtsklick auf die Instanz → **Ordner** → `minecraft\shaderpacks`.)
4. Die ZIP-Datei aus dem Downloads-Ordner in diesen Ordner kopieren.
5. In Minecraft **Mystic_Realism_Shaders** anklicken und **Anwenden** bzw. **Fertig** drücken. Beim ersten Laden kann es kurz dauern.

Dein Resourcepack läuft ganz normal zusammen mit dem Shader. Passt super zu **[Faithful + Mod-Addon](https://github.com/MikeDefeater/Faithful-x-64-1.1)**.

## Leistung

Im Shader-Menü oben bei **Profil** die passende Stufe wählen:

| Profil | Für wen |
|---|---|
| **Ultra** | Starke Grafikkarte: schärfste Schatten, feinste Wolken, Nebel und Lichtstrahlen |
| **High** | Gleicher Look, etwas weniger Detail (Standard) |
| **Mid** | Mittlere PCs |
| **Low** | Schwächere PCs, Effekte werden reduziert |
| **Very Low** | Sehr schwache PCs / Laptops: keine Lichtstrahlen und kein Nordlicht |

Tipp: Wenn es ruckelt, zuerst **Schattenauflösung** und **Schattenreichweite** runterdrehen und die **Lichtstrahlen** ausschalten. Das bringt am meisten.
